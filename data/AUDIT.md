# 地图数据复查（2026-10-30）

本报告针对替换前的历史图库。客户端主库现已切换到天地图；新主库核验及覆盖限制见 [天地图核验](TIANDITU-AUDIT.md)。客户端不再保留历史补充；本文仅为原图库历史审计记录。

结论：离线转换和区县提取完整，但原始图库存在历史区划、几何拓扑及跨模式范围不一致的问题。可用于历史地图浏览和示意制图，不能据此声称提供现行、精确、拓扑有效的行政区数据库。

## 已修复

ECharts 4.8.0 西藏省图 540000.json 有两个“山南市”，其中一个是 coordinates=[] 的空 Polygon，导致生成的分区名称和点击链接重复。ECharts 会跳过空要素，普通包围盒检查因此漏报。

生成阶段现在仅排除有非空同名替代项的空要素；无替代项的空要素或仍有重复名称时直接失败。修复后西藏有 7 个非空要素和唯一的山南市入口。原始快照和 SHA 校验值不变，处理记录写入 resources/region-links-report.json 的 corrections。回归测试和客户端截图验证了此结果。

## 仍存在的源数据问题

### 分区与纯轮廓范围不同

城市两种模式均与原始 JS 相同，说明差异已存在于源数据。截图确认平顶山纯轮廓缺少分区图中大片西部和中部区域，两种模式并非仅有内部线条差异。

| 层级   | 例子                                                       | 发现                                                               |
| ------ | ---------------------------------------------------------- | ------------------------------------------------------------------ |
| 城市   | 平顶山、塔城地区、莆田、安阳、开封、新乡、郑州、杭州、金华 | 分区合并范围与原始纯轮廓明显不同                                   |
| 省级   | 海南                                                       | 分区图含南部海域岛屿要素，取自全国图的轮廓主要是海南本岛附近几何   |
| 省级   | 台湾、香港、澳门等                                         | 省图与全国图对应轮廓的精度、岛屿或范围细节不同                     |
| 跨层级 | 东沙群岛                                                   | 城市索引存在，但广东省图无对应要素，不能从省图点击进入；搜索可打开 |
| 跨层级 | 连江县、澎湖县                                             | 台湾省图与原城市图部分离岛范围不一致                               |

筛查使用 Shapely 2.1.2，在经纬度平面上临时用 buffer(0) 处理无效几何，计算分区合并与轮廓的对称差／并集面积，超过 1% 时标记；另用 0.003 度简化复核明显异常。父省包含性筛查使用 0.03 度容差。此方法仅用于发现异常，临时修复可能改变结果，平面面积比例不是真实土地面积比例；未写回几何。

目前保留原始范围并记录问题。边界修复需要统一来源、基准日及精度，或另行设计并验证从分区生成轮廓的流程；尚未判定哪份轮廓代表正确边界。

### 严格 GIS 拓扑缺陷

用 ECharts 6.0.0 parseGeoJSON 解码后，对 854 个全国／省级／城市地图模式中的 4,212 次要素出现运行 Shapely 2.1.2 is_valid / explain_validity。区县不重复计入，省级轮廓与全国图对应要素仍有重复统计。

共 2,665 次要素出现未通过检查：城市分区 2,384、城市轮廓 35、省级分区 209、省级轮廓 18、全国分区 18、全国轮廓 1。原因包括自交、环自交、组件有效点不足。另计得 1,885 个少于三个不同坐标点的退化环及 3 个未闭合环。这是几何检查计数，不是坏文件数，也不表示对应区域全部无法显示。

示例：全国图河北在约 (118.7617, 39.0419) 自交；安庆迎江区在约 (117.0586, 30.5186) 自交；全国图台湾存在有效点不足的组件。压缩坐标含重复点、塌缩小环，未逐项判定问题来自压缩量化还是更早的制图过程。

ECharts 能显示不代表适合 GIS 求交、面积计算、邻接分析或无缝拼接。本次没有批量重画、删岛或自动修复源边界，以免误改范围。

### 年代与覆盖

4.8.0 是 ECharts 发布包版本，不是区划日期，上游未声明统一基准日。原城市库仍有“莱芜”“那曲地区”等历史条目，各层级及模式不能保证同年、同精度。3,253 是可提取的源要素数，不是现行区县总数。

台湾省图“中国属钓鱼岛”为保留的附加要素，无独立城市入口；全国图没有独立南海插图面板；区县无乡镇／街道分区。来源与许可见 README.md 及原件 NOTICE。

14 项 Node 回归测试通过；Electron 冒烟测试检查 7,360 个模式读取、全国到区县导航、PNG 导出、偏好重载、零网络请求。额外查看西藏修复结果及平顶山两种模式截图。没有逐张人工审图，也没有与现行权威边界逐点比对。
