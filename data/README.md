# 离线行政区地图

此目录提交全国和 34 个省级地图的固定快照。应用启动、资源生成和安装包运行均不下载地图。

## 区县地图

区县独立地图由本仓库 392 张城市分区图中的 3,253 个要素生成。没有引入另一套区县边界，也没有重复提交已有几何；scripts/county-catalog.cjs 在资源准备时按要素提取，保留坐标编码和偏移，每个区县只生成一份文件，由两种显示模式共享。ID 由父城市 ID 和完整名称的 UTF-8 十六进制组成，不依赖要素顺序。

这些地图只有区县外轮廓，没有乡镇／街道边界，不能将源数据 childNum 字段解释为已有下级地图。省直管县及部分特殊区域沿用原仓库层级，不作为现行区划统计。

原始城市及其派生区县数据的使用条款见根 README 的 License 段落：大陆数据来自高德，打包代码的 MIT 不代表数据内容授权；台湾数据说明指向政府资料开放授权条款第 1 版。资源生成时原样复制该说明到 CITY-MAPS-SOURCE-NOTICE.txt。此派生操作不会改变原始数据条款。

核查过的其他来源：echarts-china-counties-js@1.0.2 的 3,253 份原始 GeoJSON 也主要是单区县轮廓，README 标明高德数据条款，未用于本项目；geoBoundaries CHN ADM3 元数据标明 2017 年、2,867 个单元和 ODbL，未用于替换当前区划。当前不增加乡镇层级。

## 全国和省级快照

- 来源：npm 官方发布的 echarts@4.8.0 包，下载地址见 regions/manifest.json。
- 校验：导入时校验整个 tgz 的 SHA-512（npm 发布元数据）；每次 prepare:assets 校验逐文件 SHA-256。
- 许可证：保留上游发布包的 LICENSE.txt、NOTICE.txt。全国及省级资源不使用本仓库城市地图的 MIT 标签。
- 版本：历史区划快照；4.8.0 是发布包版本，不是行政区划日期。上游未声明统一区划基准日。
- 原件：regions/ 中 36 份 JSON 和两份许可文件逐字节复制，Git 禁止换行转换，Prettier 忽略该目录。
- 衍生：省级纯轮廓取全国图中相应省份的几何；分区图使用对应的省图，二者精度可能不同。

地图内容沿用上游，包括岛屿等附加要素；不重画边界，不声明为现行标准地图。全国图中没有独立的南海插图面板，保留的是上游几何表现。生成阶段排除西藏省图中几何为空的同名“山南市”占位要素，保留非空原要素及全部原件，处理记录写入 region-links-report.json。

全量结构检查及已知源数据问题见 [地图数据审计](AUDIT.md)。部分城市分区与纯轮廓范围明显不同，源几何存在严格 GIS 拓扑缺陷。运行 npm run audit:maps 可复查转换、提取、层级、坐标及文件完整性。

## 重新导入

从 manifest 指向的地址下载原始 tgz，然后在 desktop 目录运行：

    node scripts/import-regions.cjs artifacts/echarts-4.8.0.tgz
    npm run prepare:assets

导入脚本需要系统 tar；仅供维护时使用。正常构建直接读取已提交的 regions/，不需要原始 tgz 或网络。

## 层级对应

全国和省级 ID 使用全国源文件中的六位行政区代码。原有 392 个城市保留拼音 ID，不虚构其行政代码。

省级要素到城市的链接只在已知省份内匹配，处理“市”后缀与现有台湾名称的简繁差异。歧义和未匹配项写入生成资源中的 region-links-report.json。当前唯一未匹配项为台湾图中的“中国属钓鱼岛”附加要素，保留显示，不设置城市入口。

直辖市及港澳的省级地图直接显示区县分区，不再增加重复的市级跳转。原有同名城市入口仍保留，旧版城市选择偏好会自动迁移。
