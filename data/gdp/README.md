# GDP 离线资料

当前整理的是 **2024 年、当年价格、人民币亿元**的 GDP 总量快照，采用所存官方版本的公布值，不代表截至下载日的最新核实数。应用暂未接入 GDP 展示；这些文件供后续功能使用，运行应用无需联网。

合计175条。港澳台、其他省份的城市和县区尚未收录；缺失不填零、不插值、不用其他年份补齐。2025年部分地方已有统计公报，本批先保留同年的明确来源，不能在界面中称为“最新GDP”。

## 文件

- gdp-2024.json：整理后的观测值，包含地图ID、原表名称、来源、原文件和核算状态。年份、币种、单位和价格口径在文件顶层统一声明。
- coverage-2024.json：覆盖数量、缺失地图ID及统计范围例外。
- manifest.json：官方来源链接、广东官方ZIP内的原始成员路径、获取日期和每份原件的SHA-256。sources/保存原始字节。
- nbs-2024-transcription.csv：对照国家统计局图片表逐行转录的全国和省级值。广东数据直接解析原HTML表，不经OCR。
- region-aliases.json：4个有明确所属城市的来源简称与地图名称对应，不进行模糊匹配。

官方入口：[中国统计年鉴2025](https://www.stats.gov.cn/sj/ndsj/2025/indexch.htm)、[广东统计年鉴2025](https://stats.gd.gov.cn/gdtjnj/content/post_4810393.html)。广东HTML原表取自官方页面提供的ZIP，提取时通过ZIP的CRC检查，文件内容未改写；ZIP中的最外层中文目录省略于manifest成员路径。

## 地区与口径

来源名称按行政层级和所属城市精确匹配现有地图目录，生成时要求唯一匹配。地图的天地图来源代码不被当作已经验证的现行统计区划代码，名称匹配也不证明2024年统计范围与地图快照边界完全一致。

表23-1注明海丰县不包含深汕合作区。该记录保留scopeNote，后续未经范围核对不直接用于全县面着色。地图里的东莞、中山县级条目是整市代理，不复制市级GDP来伪装县区覆盖。

广东城市表的珠三角、粤东、粤西、粤北为经济区域汇总，不作为行政城市导入。县区表取2024年GDP列，不取相邻的2023年值或增长指数。

全国GDP直接取表3-1“国内生产总值”列，不取“国民总收入”。年鉴说明部分活动只核算在全国，各省合计略小于全国，不能要求两者相等或用省级求和替代全国。增长率和人均GDP未混入本数据集。

## 重建与检查

需要Python 3，仅使用标准库。先生成现有地图目录，再离线解析本目录原件：

```sh
npm run prepare:assets
python scripts/prepare-gdp.py
python -m unittest discover -s tests -p "gdp_test.py"
```

重建先校验原件哈希，再校验地区唯一匹配、数值、重复记录和预期条数。更新数据时同时更新来源原件、manifest和转录值，并人工对照原表复核；不能只改哈希使校验通过。原始资料是2025版年鉴的固定快照，后续修订应明确替换版本，保持同图同年同口径。

全国和31省是本批完成的全国范围；城市、区县目前仅完成广东。扩充其他省份时优先采用省统计局同年分市、分县GDP表，逐省记录覆盖和范围差异。国家数据查询页本次返回403，未将其作为已验证的稳定接口；上海统计局年鉴和公报入口可访问，但尚未纳入本批数值。
