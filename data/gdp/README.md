# GDP 离线资料

按年份保存官方公布的GDP总量，统一为**当年价格、人民币亿元**。最新年度优先查各统计局的年度经济运行发布、统一核算结果和统计公报；年鉴用于历史资料和修订核对。

2025年全国GDP为1,401,879亿元，直接取国家统计局公报，不取国民总收入或省级求和。省级数据均采用所存年度版本，不宣称已排查2026-11-02前的全部后续修订。年度总量按现价计算，文中的“不变价”用于增长率。

客户端通过“专题 → 人口与经济 → 地区生产总值（GDP）”展示离线资料。可分别查看2025年和2024年资料。上海2024年区级金额按工作簿收录，市级总量采用原有年鉴值。打包仅包含年度观测值、来源信息与范围限制，不包含来源原件。缺失地区使用中性色；存在明确范围疑问的地区停止着色。

## 文件与复核

- gdp-2025.json、gdp-2024.json：各年观测值，包含地图ID、名称、金额、来源文件和核算状态；年份、币种、单位及价格口径在顶层声明。
- coverage-2025.json、coverage-2024.json：覆盖数量、缺失地区和统计范围例外。
- manifest-2025.json：逐地区的官方链接、页面发布日期、金额转录值、原文摘录、提取方式和原件SHA-256。来源原件保存在sources/，不改写HTML字节。
- manifest.json：2024快照的年鉴来源、获取日期、广东官方ZIP成员路径及原件SHA-256。
- nbs-2024-transcription.csv：人工核对国家统计局图片表后的全国、省级转录值。广东2024年数据直接读取原HTML表。
- region-aliases.json：4个明确所属城市的来源简称与地图名称对应，不进行模糊匹配。
- map-scope.json：启用的年度及地图范围限制。当前两江新区尚未核实年度统计范围与地图边界的对应关系，不参与着色；地区ID必须存在于当前地图目录。

2025年金额逐条对照原文。重建先核对原件哈希，再检查地区唯一映射、来源身份、年度、单位、金额、发布日期和重复记录。HTML正文金额从GDP句子提取；省级上海、青海读取已复核表格摘录，广东城市和东丽区按指定行列读取并核对表头。贵州金额被HTML标签分隔出的空格按原数字连接。仅在页脚出现某省名字不作为地区身份依据；青海表题只写“全省”，由其官方域名确认发布机构。

发布日期采用页面显示或元数据，可能与URL日期不同，例如广西实际发布日期是2026-01-26、青海是2026-01-23。江西的发布日期来自原HTML内的pubDate字段。哈希只能证明原件未变，不能代替人工判断统计口径。

PDF、DOCX、Excel和图片采用明确标记的人工复核转录（reviewed-transcription），同时保存原件与独立的.review.txt，记录PDF页码或工作表单元格、原值和单位。重建验证两者哈希、转录内容、来源发布页及数值换算，但不宣称自动解析或OCR验证了二进制原件。扫描页及字符异常的徐汇公报已渲染目视核对。内蒙古工作表22取D列全年额，不取B列前三季度；内蒙古与北辰按原表显示的一位小数四舍五入，保留底层原值及格式供复核。延庆原文万元按10000换算为亿元。

更新时一并更新原件、来源记录和金额，重建后人工复核差异。2025年发布中已出现部分2024年最终核实值；现有2024文件仍是明确标记的年鉴历史版本，未将这些修订值悄悄混入。

## 地区与口径

数据按行政层级及所属城市精确对应现有地图目录。天地图来源代码不被当作已验证的现行统计区划代码，名称匹配也不证明统计范围与地图快照边界完全一致。

广东2024年县区表注明海丰县不含深汕合作区，记录保留scopeNote，未经范围核对不直接用于全县着色。地图中东莞、中山的县级条目是整市代理，不复制市级GDP伪装县区覆盖。

广东城市表中的珠三角、粤东、粤西、粤北为经济区域汇总，不作为行政城市导入。县区表取2024年GDP列，不取相邻的2023年金额或增长指数。全国核算包含部分不分配到省级的活动，各省合计可以小于全国。

## 离线重建

需要Python 3，仅使用标准库。依次运行：

    python scripts/prepare-gdp.py --year 2025
    python scripts/prepare-gdp.py --year 2024
    npm run prepare:assets
    python -B -m unittest discover -s tests -p "gdp_test.py"

不传--year时重建2025年。原件已在仓库中，重建不访问网络。2024年官方年鉴入口：[国家统计局](https://www.stats.gov.cn/sj/ndsj/2025/indexch.htm)、[广东省统计局](https://stats.gd.gov.cn/gdtjnj/content/post_4810393.html)。广东原HTML来自官方ZIP，提取时通过CRC检查；manifest中省略ZIP最外层中文目录。

Python重建需要已有的resources/catalog.json；首次检出先运行npm run prepare:assets，生成目录及现有快照的应用资源。客户端接口与分层见[GDP客户端接入](../../docs/gdp-client.md)。
